# 10. 版本变化

> 适用版本：0.0.9 · 更新：2026-11-02 · [返回目录](../GUIDE.md)

每个版本的完整说明在[发布页](https://github.com/Scorpioxyb/celia/releases)。这里只记录**和日常操作有关的变化**，以及**指南里哪些章节跟着改了**。

---

## 0.0.9（2026-11）

**操作上的变化：**
- **小修复**：从 0.0.9 起会发 0.0.9.1 这样的小修复，默认自动检查和下载，下次打开 Celia 时生效，出错自动退回。设置 → 关于与更新 里能看当前修复、手动退回上一版、关掉「自动安装小修复」。
- **每日跟进**：设置 → 助手 → 每日跟进 打开后，助手每天在定好的时间写好跟进草稿，放在「今天」页，**你点发送才会发出**，超过 3 天自动作废。默认关闭。
- **业务记忆**：设置 → 业务 → 业务记忆，分客户画像、开发信写法、工厂能力三份。在对话里跟助手说「记住：……」，它会记进对应的一份，之后写信、评估客户时会读到；最近一次改动可以撤销。
- **周报**：询盘与报价 → 概览，每周一早上 9 点生成。
- **客户阶段只剩五个**：待开发、已联系、洽谈中、合作客户、暂不跟进，另有「未指定」。原来的阶段自动对应过来。
- **新增客户、联系人的表单变成两列分区**：国家可以用中文、英文或代码搜索；时区跟着国家自动填；公司规模按领英的人数区间选。
- **客户详情多了「联系人」标签**，以卡片列出所有联系人，可以直接编辑。
- **合并重复客户**、**快速新建客户**（客户页或 ⌘K）。
- **询盘卡片显示报价金额**：询盘没填金额时，显示当前那一版报价，草稿会注明。
- **报价换币种**：告诉助手目标币种和汇率，生成一版新报价，旧版保留。助手不会自己查汇率。
- **导入**：已有的公司用「补齐缺失资料」补联系人和跟进记录；导入前会列出同一家公司几行写得不一样的地方；同一份名单再导一次会提示已导入过，不会重复写入。
- **在其他 AI 工具里用 Celia**：设置 → 账号与连接 → 本机连接（MCP）。联系人照样只以编号交出去，编号用完可以换一组。
- **修好了「扩展」页读不出本机技能列表的问题**
- **修好了助手设置里两项保存不了的问题**：「允许 Agent 为子智能体选择模型」和「设为新任务默认」。
- **侧栏**：折叠按钮移到 Celia 标志右边，也可以按 ⌘B；侧栏一直通到窗口顶部。

- 从 0.0.8 更新到 0.0.9 要下载**完整包（约 297 MB）**，下载前设置页会写明大小。

**需要你做的：**
- 想要每天自动准备跟进草稿，到 设置 → 助手 → 每日跟进 打开，选好时间。
- 有几条你经常提醒助手的规矩（不做的材料、开发信长度），可以直接写进 设置 → 业务 → 业务记忆。

**指南：** 01 安装与更新、02 首次设置、03 每日工作流程、04 客户与联系人、05 让助手工作、06 询盘与报价、08 数据与隐私、09 遇到问题怎么办 跟着改了；07 领英 没有变化。

## 0.0.8（2026-10）

**操作上的变化：**
- **助手直接做事，不再一件件问你。** 发邮件、发领英私信和帖子、改客户资料、删除客户，助手都会直接做。做过的事记在客户时间线和对话里，可以撤销。原来「执行前核对」三档、「哪些事会先问你」、领英的「领英发送」和「私信免逐条确认」开关都去掉了。
- **「待确认」改名「待处理」**，只放三类事：发送结果不明（或已发出但跟进没记上）的邮件、缺联系渠道的客户、中断的任务。处理完就会消失。「发送所选」也去掉了。
- **今天页换了新的开头**：问候加一句每天不同的话，旁边是待处理、到期跟进、新询盘三个数字，下面一个按钮告诉你先做哪件事。名字取自「我的资料」，没填时显示「Celia」。
- **删除客户一步完成**：点「删除客户」就移进客户回收站，弹窗里可以「撤销删除」，之后也能在客户回收站里恢复。
- **领英发帖恢复**，助手可以直接发。
- **设置 → 助手** 只留「暂停助手」一个开关。
- **模型只在助手自己的设置里管**：设置 → 账号与连接 → 模型服务 →「管理模型服务」。第一次用某个服务时不再弹「客户资料会发送给它」的提示。
- **网页研究** 一行显示能不能用；还没有 DeepSeek 密钥时，可以直接点「添加 DeepSeek 服务」。
- 客户的邮箱和电话照旧只以编号交给模型，真实值只在发出邮件或私信的那一刻才填进去。

- 这次更新要下载**完整包（约 298 MB）**：底层框架有改动，没法只下载改动部分。下载前设置页会写明大小。

**需要你做的：**
- 如果你之前依赖「发出前确认」来把关，现在请改成：交代任务时说清楚「先写给我看，别发」，或者先打开「暂停助手」。
- 每天先看一眼「待处理」，把发送结果不明的邮件核对掉。

**指南：** 02 首次设置、03 每日工作流程、04 客户与联系人、05 让助手工作、06 询盘与报价、07 领英、08 数据与隐私、09 遇到问题怎么办 跟着改了；01 安装与更新 没有变化。

## 0.0.7（2026-10）

**操作上的变化：**
- **设置重新分成六类**：账号与连接、助手、业务、外观、数据、关于与更新。原来的「模型与用量」「邮箱与发送」「助手自主程度」「应用更新」「数据与备份」都搬进了这六类里。
- **助手页换了新界面**：左上角「新会话」，输入框里 `@` 引用客户、`/` 调用指令。大任务会分给几个子智能体一起做，再派核查员复核。
- **模型在助手的设置里管理**：设置 → 账号与连接 → 模型服务 →「管理模型服务」。添加服务、填密钥、设默认模型都在那里。
- **网页研究改用 DeepSeek 搜索与网页读取**，用同一个 DeepSeek key，不用另外申请。
- **改客户资料、写研究笔记直接保存**，可以在客户时间线或对话里撤销。邮件发出前仍由你确认，并且可以在待确认里**勾选多封一起发送**。领英发帖暂停。
- 领英的开关和专用浏览器登录搬到了 设置 → 账号与连接 → 领英。
- 打开 Celia 时有启动画面，会跟随你选的主题颜色。
- 设置 → 关于与更新 → 本机维护 里可以看到「为回退保留的上一版」，用得稳定后可以把它移到废纸篓腾空间。
- 更新时下载的临时文件，装好后直接删除，不再放进废纸篓。

**需要你做的：**
- 从 0.0.6 更新后，废纸篓里可能多出 Celia 的临时文件（可能接近 1 GB）和 `Celia-business-skills-` 开头的文件夹，可以直接清空，见[安装与更新 → 常见问题](01-install.md#常见问题)。
- 0.0.7 的设置里没有模型「测试连接」按钮了。想确认模型能用，到助手页发一句话试试。

**指南：** 01 安装与更新、02 首次设置、03 每日工作流程、05 让助手工作、07 领英、08 数据与隐私、09 遇到问题怎么办 跟着改了；04 客户与联系人、06 询盘与报价 没有变化。

## 0.0.6（2026-10）

**操作上的变化：**
- 开着加速器、代理时，连模型、检查更新、收发邮件都不再报错。连接失败会说明原因，并可以复制诊断信息。
- 设置页重新整理。邮箱只需要选服务商、填邮箱和授权码；新增网易企业邮箱。数据与备份可以看到备份记录，并且可以立即备份。
- 导入名单可以导入联系人、电话、跟进记录了；只在第一行写公司名的表格也能正确识别。
- 所有表单的必填项都标了红色星号。
- 领英私信打开「免逐条确认」后，不再限制每日条数。
- 之后的更新大多只需要下载改动的部分。

**需要你做的：** 如果你之前提示「无法更新（PRIVATE_DNS_BLOCKED）」，请手动安装一次 0.0.6，见[手动更新](01-install.md#三手动更新自动更新失败时用)。

**指南：** 第一次发布，全部章节都是新写的。

## 0.0.1 – 0.0.5

主要是安装和更新方面的修复，日常操作没有变化。
