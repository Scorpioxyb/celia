# 9. 遇到问题怎么办

> 适用版本：0.0.9.9 · 更新：2026-11-11 · [返回目录](../GUIDE.md)

**目的**：常见问题自己就能处理；处理不了的，知道该把什么发给发布者。

---

## 一、助手连不上模型

**先做这一步**：到左边的「助手」页发一句简单的话，比如「你好」。回答不了时，对话里会显示出错原因。

再到 设置 → 连接 → 模型与研究 → 模型服务，点「管理模型」，看 DeepSeek 下面有没有设好默认模型、密钥有没有填；没有的话，按[首次设置 → 模型服务](02-setup.md#一模型服务助手的大脑)重新设好默认模型。

| 出错原因 | 怎么办 |
|---|---|
| 密钥不对或已失效 | 在「管理模型」的面板里重新粘贴 API key，点「保存模型设置」 |
| 账户余额不足 | 到模型服务商后台充值 |
| 请求过于频繁 | 等一两分钟再试 |
| 服务商拒绝了请求 | 模型名称填错，或者这个模型你的账户没有开通；到服务商后台核对模型名 |
| 服务地址指向本机或受保护的网络地址 | 服务地址填错，或者 DNS 被改过；核对地址，仍不行就复制诊断信息发给发布者 |
| 网络被拒绝连接 / 连接被中途断开 / 等待连接超时 | 大多和加速器或代理有关，见下面「开着加速器或代理」 |
| 找不到服务地址 | 检查网络是否正常 |
| 安全证书校验失败 | 检查电脑时间是否正确；有些代理软件会替换证书，换个节点或关掉代理试试 |

### 开着加速器、VPN 或代理

很多加速器会接管网络，偶尔会影响 Celia 连接模型、检查更新和收发邮件。0.0.6 起 Celia 已经能兼容大多数加速器。仍然连不上时：

1. 在加速器里把下面的地址设为「**直连**」（不走代理）：
   - `api.deepseek.com`（模型）
   - `github.com`、`api.github.com`（检查更新）
   - 你的邮箱服务器，比如 `imap.qq.com`、`smtp.qq.com`
2. 或者暂时关掉加速器，再让助手试一次。

### 助手页顶部写着「助手停止了」

助手意外退出好几次，或者没能启动时，助手页顶部会显示「助手停止了」和原因，顶栏显示「助手未启动」。点右边的 **重新启动助手**，恢复后对话列表会自动刷新。点了还是不行，就退出并重新打开 Celia；仍然这样，把那条提示截图发给发布者。如果提示里说启动时出错，而你刚改过模型，先到 设置 → 连接 → 模型服务 检查。

### 还是不行

1. 打开 设置 → 数据与更新 → 本机维护，点「**运行自检**」，它会检查数据文件夹、配置和助手能否正常启动。
2. 把对话里的出错提示和自检结果截图，发给发布者。截图前确认画面里没有客户资料和 API key。

### 助手说不能读网页

助手会直接说出原因，比如“DuckDuckGo 要求人工验证”或“还没有 DeepSeek 密钥”。再到 设置 → 连接 → 模型与研究 →「网页研究」看状态：

- 用的是**免费搜索**时，来源要求验证或连不上，就会暂时搜不到或结果很少。过半小时再试；添加 DeepSeek key 后，「自动」会改用 DeepSeek 搜索。
- 固定成 **DeepSeek 搜索**又显示「需要 DeepSeek 密钥」时，按[首次设置 → 网页研究](02-setup.md#网页研究默认自动选)添加 DeepSeek 服务，或者改回「自动」。
- 某个网页读不了，多半是这个网站不让程序读取，换一个公开网页即可。

## 二、更新失败

| 现象 | 怎么办 |
|---|---|
| 提示「无法更新……（PRIVATE_DNS_BLOCKED）」 | 手动装一次新版本，见[安装与更新 → 手动更新](01-install.md#三手动更新自动更新失败时用) |
| 在 0.0.8 里更新，提示「程序内部错误……（ENOENT）」 | 这是 0.0.8 更新程序在部分电脑上的老问题。资料还在，Celia 仍是 0.0.8，可以照常用。手动装一次新版本就好，见[安装与更新 → 手动更新](01-install.md#三手动更新自动更新失败时用)；从 0.0.9 起不会再这样 |
| 下载很慢或超时 | 换个网络，或者按上面的方法把 GitHub 设为直连；还不行就手动更新 |
| 从 0.0.9.4 或更早的版本点了更新（提示里写的是 0.0.10），之后 Celia 打不开，或提示「Celia 未能启动」 | **资料还在。** 这是更新到 0.0.9.5 时的已知问题：更新进行中又打开了一次 Celia（比如点了程序坞里的图标），新版本没能启动，被换回了旧版本，而资料已经升级，旧版本读不了。0.0.9.9 起修好了：更新时再打开 Celia 只会提示「正在更新」。到[发布页 0.0.9.5](https://github.com/Scorpioxyb/celia/releases/tag/v0.0.10) 下载 `Celia-0.0.10-arm64.dmg`（就是 0.0.9.5），打开后把 Celia 拖进「应用程序」，提示时选「替换」，再打开 Celia。之后的小修复会自动补上。「应用程序」里多出来的 `Celia.app.previous` 不用管，下次更新时会自动清掉。还是打不开就把提示截图发给发布者 |
| 其他情况下更新后打不开 | Celia 会自动回到旧版本。把 设置 → 数据与更新 → 应用更新 里的提示截图发给发布者 |
| 打开时提示「Celia 未能启动」，用过「测试样例」 | 用的是 0.0.9 时可能遇到。先退出 Celia，在访达按 ⇧⌘G 前往 `~/.celia/data`，把里面的 `test-samples` 文件夹移到桌面，再打开 Celia。你的客户资料不受影响。还是打不开就把提示发给发布者 |

## 三、邮箱连不上

| 现象 | 怎么办 |
|---|---|
| 收信或发信失败，提示登录或认证失败 | 授权码填错，或者填成了邮箱登录密码。重新生成授权码，见[首次设置 → 邮箱](02-setup.md#二邮箱) |
| 提示连接失败 | 确认邮箱网页版里已经开启了 IMAP/SMTP；开着加速器的，见上面 |
| 网易企业邮箱连不上 | 有的公司限制了外部客户端，请公司邮箱管理员开启「客户端登录」 |
| 收信正常、发信失败（或者反过来） | 两边是分开测试的，按失败那一边的提示处理 |

## 六、出现错误代码

有些提示会在括号里带一个错误代码，比如 `（PRIVATE_DNS_BLOCKED）`。把**整句提示**和**错误代码**截图发给发布者就行。

## 怎么反馈问题

在 [Issues](https://github.com/Scorpioxyb/celia/issues) 里写：

1. Celia 版本号（设置 → 数据与更新 → 应用更新 →「当前版本」）；
2. 你做了什么、看到了什么，截图更好；
3. 「运行自检」的结果，如果有的话。

**不要发**：客户资料、API key、邮箱授权码、`~/.celia` 里的文件。
