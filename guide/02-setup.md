# 2. 首次设置

> 适用版本：0.0.9.6 · 更新：2026-11-10 · [返回目录](../GUIDE.md)

**目的**：让助手能工作、能收发邮件、写出来的邮件署你的名字。
**什么时候用**：装好 Celia 后第一次使用；换邮箱或换模型时。

所有设置都在左边的 **设置**。设置分六类：**连接、助手、我的公司、跟进、外观、数据与更新**。每一类里分成几组，每一行左边是名称和说明，右边是按钮或开关，状态直接写在旁边，比如「邮箱：未设置」。邮箱、模型服务这类要填一整张表的，点右边的按钮会在右侧打开一个面板。

带红色星号 `*` 的是必填项。

---

## 一、模型服务（助手的大脑）

助手需要一个大模型服务才能工作。Celia 本身不提供模型，需要你自己准备一个 API key（相当于模型服务的账号密码），费用由你和服务商直接结算。

**目前推荐 DeepSeek**，它做过完整的真实测试。

### 拿到 DeepSeek 的 API key

1. 打开 DeepSeek 开放平台（platform.deepseek.com），注册并登录。
2. 充值少量余额。日常使用费用很低，可以在平台后台查看用量。
3. 在「API keys」页面创建一个新 key，复制下来。**建议专门给 Celia 建一个，不要和别的软件共用**，这样用量看得清楚。

### 填到 Celia 里

1. 打开 **设置 → 连接 → 模型与研究**，在「模型服务」一行点 **管理模型**，右侧会打开「模型服务」面板。
2. 在「服务商」里选 **DeepSeek**，点 **添加模型服务**，展开它，在密钥一栏粘贴 API key。如果出现「我知道客户资料会发给这个服务商处理（邮箱和电话仍先换成编号）」，勾上。
3. 在 DeepSeek 下面选一个模型，点 **设为默认**。
4. 点 **保存模型设置**。保存时本机服务会重启几秒，对话记录都会保留；助手正在工作时会先问你要不要停下并保存。
5. 回到助手页发一句话试试，助手能回答就说明设置好了。已有对话会保留。
   - 回答不了的话，见[遇到问题怎么办](09-troubleshooting.md#一助手连不上模型)。

- 想发图片给助手，要在对应的模型后面勾上 **支持图片**，见[让助手工作 → 图片](05-assistant.md#发图片给助手)。
- 助手、每日跟进和网页研究共用这里的默认模型，不用分别设置。
- 从旧版助手更新上来的，第一次打开时 Celia 已经把你以前设过的模型和密钥搬到这里，不用重填。

> API key 只保存在你电脑上，只有你的账号能读，界面上也不会再显示出来（保存后只显示最后 4 位）。**不要把 API key 发到聊天里，也不要发给任何人。**

### 网页研究（默认自动选）

助手查公司、找联系人时，需要搜索和读取公开网页。0.0.9.6 起默认是**自动**：

- 模型服务里有 DeepSeek key 时，用 **DeepSeek 搜索**，结果最全，按 DeepSeek 计费；
- 没有 DeepSeek key 时（比如走 Magpie 或别家模型），用**免费搜索**（DuckDuckGo 和 Mwmbl），不用密钥、不花钱，但结果少一些。

打开 **设置 → 连接 → 模型与研究**，「网页研究」一行显示「可以使用」就行，描述里会写现在用的是哪一种。下拉框可以固定成「免费搜索」或「DeepSeek 搜索」；固定成 DeepSeek 搜索又没有 key 时，会显示「需要 DeepSeek 密钥」，点 **添加 DeepSeek** 按上面的步骤做。

免费搜索的来源搜多了会要求人工验证。这时 Celia 让这个来源暂停 30 分钟，先用另一个，不会绕过验证；助手也会告诉你这次只用上了哪个来源。

## 二、邮箱

连上邮箱后，Celia 可以收客户的回复、替你发邮件。

### 先在邮箱网页版拿「授权码」

大多数邮箱不允许软件直接用登录密码，需要一个单独的「授权码」，有的叫「客户端专用密码」：

- **QQ 邮箱**：网页版 → 设置 → 账号 → 开启「IMAP/SMTP 服务」→ 按提示生成 16 位授权码。
- **163 邮箱**：网页版 → 设置 → POP3/SMTP/IMAP → 开启 IMAP/SMTP → 新增授权密码。
- **网易企业邮箱**：网页版 → 设置 → 客户端设置，开启 IMAP/SMTP；如果公司开了「安全登录」，再生成「客户端专用密码」。有些公司由管理员统一设置，打不开的话请找公司邮箱管理员。
- **Gmail**：需要先开两步验证，再生成「应用专用密码」。
- **Outlook / Hotmail**：微软要求另一种登录方式，Celia 暂不支持。

Celia 里选好服务商后，授权码输入框下面有「如何获取授权码」的链接，点开就是该邮箱的官方说明。

### 填到 Celia 里

1. 打开 **设置 → 连接 → 邮箱与领英**，在「邮箱」一行点 **设置邮箱**（已经设过的显示 **修改**），右侧会打开邮箱面板。
2. **邮箱服务商**：从列表里选。服务器地址、端口这些会自动填好，不用管。
3. **邮箱地址***：你的完整邮箱。
4. **授权码***：粘贴刚才拿到的授权码。**不是邮箱登录密码。**
5. 点 **测试并保存**。Celia 会分别测试「收信」和「发信」，结果会分开显示：
   - 两边都成功：完成。
   - 一边失败：页面会写明是哪一边、什么原因。常见原因是授权码填错或者邮箱没开 IMAP/SMTP。
6. 列表里没有你的邮箱时，选「其他」，展开「手动设置服务器」，按你邮箱的官方说明填写。

### 定时收件（可选）

在邮箱面板的「收取客户回复」里可以打开「定时收件」（默认关闭），Celia 会定时检查新邮件。检测到客户回复时，会**暂停给这位客户的下一封跟进**，等你处理。

## 三、我的资料

助手起草邮件时，签名、电话这些从这里取。

1. 打开 **设置 → 我的公司**，在「姓名、公司和签名」一行点 **填写**（已经填过的显示 **修改**），右侧会打开「我的资料」面板。
2. 填写姓名、职位、公司、电话、邮件签名，点 **保存我的资料**。

这些信息保存在本机，不交给模型。留空的项目，助手起草时会提醒你补上，不会自己编。

---

### 时区

Celia 自动跟随电脑的时区，「今天」、到期跟进和每日跟进都按它算。要用别的时区，到 **设置 → 我的公司 → 时区**，关掉「跟随系统时区」，选好后保存，马上生效。

## 四、暂停助手

0.0.8 起，助手可以**直接做事**：改客户资料、写研究笔记、发邮件、发领英私信和帖子、删除客户，都不再一件件问你。做过的事都记在客户时间线和对话里，可以撤销；删除的客户进客户回收站，可以恢复。

**设置 → 助手** 分三组：

**工作方式**

- **助手可以访问哪里**：选「访问模式」，决定助手能不能碰任务文件夹以外的东西。三种：
  - **默认**：越出任务文件夹前，先问你；
  - **自动审查**：由模型审查后决定，拿不准就不允许；
  - **完全访问**：不再询问；受保护的 Celia 数据仍然不能访问。

  助手页输入框下方的「访问模式」切换的是同一个设置。所有对话和每日跟进都用这个模式，重启 Celia 后也保持。
- **暂停助手**：遇到情况想让一切先停下来，就打开它。正在做的任务（包括每日跟进）和定时收件都会停止，暂停期间助手不接新消息。恢复后，定时收件需要你再手动打开。暂停只在这一次打开 Celia 期间有效，重新打开后不保留；暂停期间每日跟进到点仍会启动。

**每日跟进**（0.0.9 起，默认关闭）

- 打开「每天早上准备跟进草稿」，选准备时间。到点后助手给该跟进的客户写好草稿，放在「今天」页，**你看过、点发送才会发出**。见[每日工作流程](03-daily.md#今天准备好的草稿打开了每日跟进时)。

**须知与记忆**

- **须知与长期记忆**：点 **查看和修改**，在右侧面板看和改助手的须知和长期记忆，只影响助手。
- **查找历史对话**：点 **搜索**，见[让助手工作 → 查找历史对话](05-assistant.md#查找历史对话)。

## 五、把你的工作方法教给助手（推荐）

打开 **扩展 → 技能**，有三份「引导设置」，点「开始整理」，按提示一题一题回答，确认后保存：

1. **客户画像**：你要找什么样的客户，哪些客户不做。
2. **开发信**：你习惯的开场、语气、邮件长度。
3. **工厂能力**：你们的工艺、材料、设备、检验能力。

填好以后，助手研究客户、写开发信时会按你的方法来。这三份会出现在 **设置 → 我的公司 → 业务记忆** 里（工厂能力那一行还有 **按表格填写**，可以直接按表格填）：在对话里跟助手说「记住：我们不做钛合金」这样的话，它会记进对应的一份；你也可以直接改，最近一次改动可以撤销。见[让助手工作 → 业务记忆](05-assistant.md#八业务记忆让助手记住你的规矩)。

## 六、在其他 AI 工具里使用 Celia（可选）

如果你也用 Codex 这类 AI 工具，可以让它直接查 Celia 里的客户、写信、发送：

1. 打开 **设置 → 连接**，在「在其他 AI 工具里使用 Celia」一组的「本机连接（MCP）」点 **复制配置**（复制失败的话，展开「查看配置」手动选中复制）。
2. 把这段配置加到那个工具的 MCP 设置里。
3. 使用时 Celia 要开着。

联系人照样只以「联系人编号」交给那个工具，不交真实的姓名、邮箱和电话。下面的 **联系人编号** 一行显示这一组用了多少（每组 1000 个）。快用完时点 **换一组新编号**：配置不用改，旧记录都保留，旧编号不会指到别人；那个工具之前拿到的编号不能再用，让它重新查一次客户即可。

## 常见问题

**设置里每一项旁边的状态是什么意思？**
告诉你这一项现在是否正常，比如「邮箱：已连接」「最近备份：昨天」。有问题时会直接写出来。

**保存模型服务要花钱吗？**
不花钱，保存时不会调用模型。之后助手每次工作才按用量计费。邮箱测试也不花钱。

**网页研究要另外付费吗？**
用的是同一个 DeepSeek key，费用一起算在 DeepSeek 的用量里。
