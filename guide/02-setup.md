# 2. 首次设置

> 适用版本：0.0.6 · 更新：2026-10-18 · [返回目录](../GUIDE.md)

**目的**：让助手能工作、能收发邮件、写出来的邮件署你的名字。
**什么时候用**：装好 Celia 后第一次使用；换邮箱或换模型时。

所有设置都在左下角的 **设置**。左边是分类，右边是内容；每一页最上面会有一句话告诉你现在的状态，比如「邮箱：未设置」。

带红色星号 `*` 的是必填项。

---

## 一、模型服务（助手的大脑）

助手需要一个大模型服务才能工作。Celia 本身不提供模型，需要你自己准备一个 API key（相当于模型服务的账号密码），费用由你和服务商直接结算。

**目前推荐 DeepSeek**，它做过完整的真实测试。

### 拿到 DeepSeek 的 API key

1. 打开 DeepSeek 开放平台（platform.deepseek.com），注册并登录。
2. 充值少量余额。日常使用费用很低，可以在平台后台查看用量。
3. 在「API keys」页面创建一个新 key，复制下来。**建议专门给 Celia 建一个，不要和别的软件共用**，这样用量看得清楚。

### 填到 Celia 里

1. 打开 **设置 → 模型与用量**。
2. 选择服务 **DeepSeek**，把 API key 粘贴进去，保存。
3. 点 **测试连接**：
   - 显示连接成功，就可以了；
   - 失败的话，下面会用一句话说明原因和下一步，按提示做。还是不行，见[遇到问题怎么办](09-troubleshooting.md#一助手连不上模型)。

> API key 只保存在你电脑上（`~/.celia/auth.toml`），只有你的账号能读。**不要把 API key 发到聊天里，也不要发给任何人。**

## 二、邮箱

连上邮箱后，Celia 可以收客户的回复、帮你发确认过的邮件。

### 先在邮箱网页版拿「授权码」

大多数邮箱不允许软件直接用登录密码，需要一个单独的「授权码」，有的叫「客户端专用密码」：

- **QQ 邮箱**：网页版 → 设置 → 账号 → 开启「IMAP/SMTP 服务」→ 按提示生成 16 位授权码。
- **163 邮箱**：网页版 → 设置 → POP3/SMTP/IMAP → 开启 IMAP/SMTP → 新增授权密码。
- **网易企业邮箱**：网页版 → 设置 → 客户端设置，开启 IMAP/SMTP；如果公司开了「安全登录」，再生成「客户端专用密码」。有些公司由管理员统一设置，打不开的话请找公司邮箱管理员。
- **Gmail**：需要先开两步验证，再生成「应用专用密码」。
- **Outlook / Hotmail**：微软要求另一种登录方式，Celia 暂不支持。

Celia 里选好服务商后，授权码输入框下面有「如何获取授权码」的链接，点开就是该邮箱的官方说明。

### 填到 Celia 里

1. 打开 **设置 → 邮箱与发送**。
2. **邮箱服务商**：从列表里选。服务器地址、端口这些会自动填好，不用管。
3. **邮箱地址***：你的完整邮箱。
4. **授权码***：粘贴刚才拿到的授权码。**不是邮箱登录密码。**
5. 点 **测试并保存**。Celia 会分别测试「收信」和「发信」，结果会分开显示：
   - 两边都成功：完成。
   - 一边失败：页面会写明是哪一边、什么原因。常见原因是授权码填错或者邮箱没开 IMAP/SMTP。
6. 列表里没有你的邮箱时，选「其他」，展开「手动设置服务器」，按你邮箱的官方说明填写。

### 定时收件（可选）

在 邮箱与发送 → 高级 里可以打开「定时收件」，Celia 会定时检查新邮件。检测到客户回复时，会**暂停给这位客户的下一封跟进**，等你处理。

## 三、我的资料

助手起草邮件时，签名、电话这些从这里取。

1. 打开 **设置 → 邮箱与发送**，展开「我的资料」。
2. 填写姓名、职位、公司、电话、邮件签名，点 **保存我的资料**。

留空的项目，助手起草时会提醒你补上，不会自己编。

---

## 四、助手自主程度

打开 **设置 → 助手自主程度**，这里决定助手哪些事可以自己做、哪些要先问你。

| 项目 | 规则 | 能不能改 |
|---|---|---|
| 发邮件 | 每封都要你确认 | 固定，不能关 |
| 发领英帖子 | 每条都要你确认 | 固定，不能关 |
| 领英私信 | 默认每条都要你确认 | 可以主动打开「免逐条确认」，有账号风险，见[领英](07-linkedin.md) |
| 修改客户资料 | 先给你看对比，你勾选的才生效 | 固定 |
| 保存研究笔记 | 你确认后保存 | 固定 |

**暂停助手**：遇到情况想让一切先停下来，就打开「暂停助手」。正在做的任务、定时收件、领英发送都会停止。恢复后，定时收件和领英发送需要你再手动打开。

## 五、把你的工作方法教给助手（推荐）

打开 **扩展 → 技能**，有三份「引导设置」，按提示一题一题回答即可：

1. **客户画像**：你要找什么样的客户，哪些客户不做。
2. **开发信**：你习惯的开场、语气、邮件长度。
3. **工厂能力**：你们的工艺、材料、设备、检验能力。

填好以后，助手研究客户、写开发信时会按你的方法来。之后随时可以回来修改。

## 常见问题

**设置页最上面那句状态是什么意思？**
告诉你这一页现在是否正常，比如「邮箱：已连接」「最近备份：昨天」。有问题时会直接写出来。

**测试连接要花钱吗？**
模型的「测试连接」会发一次极小的请求，费用几乎可以忽略。邮箱测试不花钱。
