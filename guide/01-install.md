# 1. 安装与更新

> 适用版本：0.0.6 · 更新：2026-10-18 · [返回目录](../GUIDE.md)

**目的**：把 Celia 装到你的 Mac 上，以后保持最新版本。
**什么时候用**：第一次安装、有新版本、更新失败时。

---

## 一、安装

**需要**：Apple 芯片的 Mac（M1、M2、M3、M4……）。Intel 芯片的 Mac 暂不支持。

1. 打开 [发布页](https://github.com/Scorpioxyb/celia/releases/latest)，下载 `Celia-版本号-arm64.dmg`。
2. 双击下载好的文件，把 Celia 图标拖进「应用程序」文件夹。
3. 在「应用程序」里双击 Celia 打开。

### 第一次打开被拦住了？

Celia 目前没有经过苹果公证，所以第一次打开时系统会拦一下。这是正常的，只需要处理一次：

1. 出现「无法验证开发者」之类的提示时，点「完成」。
2. 打开 **系统设置 → 隐私与安全性**，往下翻到「安全性」。
3. 找到「已阻止使用 Celia」，点 **仍要打开**，输入 Mac 的开机密码。
4. 再打开一次 Celia，以后就不会再提示了。

> 想确认下载的文件没被改过，可以按 [校验说明](../VERIFY.md) 核对文件指纹。

---

## 二、自动更新（平时用这个）

Celia 每天会自动检查一次有没有新版本。检查时只读取版本信息，不会带上你的客户资料或密钥。

**有新版本时：**

1. 左下角的设置图标或 设置 → 应用更新 里会出现提示。
2. 打开 **设置 → 应用更新**，先看「更新说明」，了解这次改了什么。
3. 点「查看并确认更新」，在弹出的窗口里点「确认并开始更新」。Celia 会依次：下载 → 核对签名 → **备份你的数据** → 安装 → 重新打开。
4. 如果新版本打不开，Celia 会**自动回到旧版本**，数据也会恢复。

> 从 0.0.6 升级到之后的版本开始，Celia 会优先下载只包含改动部分的小更新包；改动太大或校验不通过时，自动改用完整包。从 0.0.5 及更早版本升到 0.0.6 仍需下载完整包（约 187 MB）。

**不想自动检查**：设置 → 应用更新，关掉「自动检查更新」。之后需要时手动点「检查更新」。

---

## 三、手动更新（自动更新失败时用）

如果更新时看到下面这类提示，就需要手动装一次新版本：

- 「无法更新……（PRIVATE_DNS_BLOCKED）」
- 「下载超时」，并且反复重试都不行

这种情况常见于电脑开着加速器、VPN 或代理。0.0.6 已经修好了这个问题，但旧版本没法自己下载修复，所以只需要手动装这一次。

**步骤：**

1. 先备份（推荐）：打开 **设置 → 数据与备份**，点「立即备份」。
2. 按 ⌘Q 退出 Celia。
3. 从 [发布页](https://github.com/Scorpioxyb/celia/releases/latest) 下载最新的 `.dmg`。
4. 双击打开，把 Celia 拖进「应用程序」，提示「替换」时选 **替换**。
5. 重新打开 Celia。你的客户、设置、密钥都会保留，它们存在应用外面（`~/.celia`），替换应用不会影响。

> 如果你的电脑上有 Codex，也可以让 Codex 帮你完成上面这些步骤。发布者可以给你一段现成的说明，复制给 Codex 就行。

---

## 四、怎么看当前版本

打开 **设置 → 应用更新**，最上面就是当前版本号。

---

## 注意事项

- 只从本仓库的 [发布页](https://github.com/Scorpioxyb/celia/releases) 下载 Celia。别人转发的安装包请先按 [校验说明](../VERIFY.md) 核对。
- 卸载：把 Celia 从「应用程序」拖进废纸篓即可。你的数据还在 `~/.celia`，不要的话再自己删。

## 常见问题

**更新会不会把我的客户资料弄丢？**
不会。更新前 Celia 会自动备份，失败会自动恢复。手动替换应用也不会动 `~/.celia` 里的数据。

**更新后需要重新填密钥和邮箱吗？**
不需要。如果你发现需要重填，请把 设置 → 数据与备份 页面的提示截图反馈给发布者。
