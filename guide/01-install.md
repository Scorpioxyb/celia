# 1. 安装与更新

> 适用版本：0.0.9 · 更新：2026-11-01 · [返回目录](../GUIDE.md)

**目的**：把 Celia 装到你的 Mac 上，以后保持最新版本。
**什么时候用**：第一次安装、有新版本、更新失败时。

---

## 一、安装

**需要**：Apple 芯片的 Mac（M1、M2、M3、M4……）。Intel 芯片的 Mac 暂不支持。

1. 打开 [发布页](https://github.com/Scorpioxyb/celia/releases/latest)，下载 `Celia-版本号-arm64.dmg`。
2. 双击下载好的文件，把 Celia 图标拖进「应用程序」文件夹。
3. 在「应用程序」里双击 Celia 打开。

### 第一次打开被拦住了？

Celia 目前没有经过苹果公证，所以第一次打开时系统会拦一下。这是正常的，只需要处理一次：

1. 出现「无法验证开发者」之类的提示时，点「完成」。
2. 打开 **系统设置 → 隐私与安全性**，往下翻到「安全性」。
3. 找到「已阻止使用 Celia」，点 **仍要打开**，输入 Mac 的开机密码。
4. 再打开一次 Celia，以后就不会再提示了。

打开 Celia 时会先出现一个启动画面，依次显示「正在检查数据」「正在启动本机服务」「正在打开工作台」，一般几秒钟后进入工作台。

> 在 设置 → 关于与更新 → 本机维护 里点「查看放行指引」，可以随时再看这段说明。

> 想确认下载的文件没被改过，可以按 [校验说明](../VERIFY.md) 核对文件指纹。

## 二、自动更新（平时用这个）

Celia 每天会自动检查一次有没有新版本。检查时只读取版本信息，不会带上你的客户资料或密钥。

**有新版本时：**

1. 左边的「设置」或 设置 → 关于与更新 → 应用更新 里会出现提示。
2. 打开 **设置 → 关于与更新**，先看「更新说明」，了解这次改了什么。
3. 点「查看并确认更新」，在弹出的窗口里点「确认并开始更新」。Celia 会依次：下载 → 核对签名 → **备份你的数据** → 安装 → 重新打开。
4. 如果新版本打不开，Celia 会**自动回到旧版本**，数据也会恢复。

> 更新下载的临时文件，装好后会直接删除，不会放进废纸篓（从 0.0.7 开始）。
>
> 从 0.0.6 升级到之后的版本开始，Celia 会优先下载只包含改动部分的小更新包；改动太大或校验不通过时，自动改用完整包。从 0.0.5 及更早版本升到 0.0.6 仍需下载完整包（约 187 MB）。

**不想自动检查**：设置 → 关于与更新，关掉「自动检查更新」。之后需要时手动点「检查更新」。

### 小修复（0.0.9 起）

小问题不用等下一个版本：会发 0.0.9.1、0.0.9.2 这样的**小修复**。

- 小修复只更换 Celia 的运行部分，**不动你的资料**，也不用重新安装。
- 默认自动在后台检查和下载，下载好后会弹出通知「Celia 修复已下载」，点 **现在重启** 或下次打开 Celia 时生效。
- 修复后如果 Celia 打不开、或短时间内连续出错，会**自动退回上一版**，退回的修复不会再自动安装。
- 在 **设置 → 关于与更新** 可以看到：
  - 「当前版本」显示带修复号的版本，比如 0.0.9.1；
  - **当前修复** 和它的说明，旁边的 **退回上一版**：点了会先问你，下次打开 Celia 时退回；
  - 已下载、等重启生效的修复；
  - **自动安装小修复** 开关：关掉后不再检查、也不再下载新的修复，已经在用的修复照常使用。
- 0.0.8 收不到小修复，要先更新到 0.0.9。

## 三、手动更新（自动更新失败时用）

如果更新时看到下面这类提示，就需要手动装一次新版本：

- 「无法更新……（PRIVATE_DNS_BLOCKED）」
- 「下载超时」，并且反复重试都不行

这种情况常见于电脑开着加速器、VPN 或代理。0.0.6 已经修好了这个问题，但旧版本没法自己下载修复，所以只需要手动装这一次。

**步骤：**

1. 先备份（推荐）：打开 **设置 → 数据 → 数据与备份**，点「立即备份」。
2. 按 ⌘Q 退出 Celia。
3. 从 [发布页](https://github.com/Scorpioxyb/celia/releases/latest) 下载最新的 `.dmg`。
4. 双击打开，把 Celia 拖进「应用程序」，提示「替换」时选 **替换**。
5. 重新打开 Celia。你的客户、设置、密钥都会保留，它们存在应用外面（`~/.celia`），替换应用不会影响。

> 如果你的电脑上有 Codex，也可以让 Codex 帮你完成上面这些步骤。发布者可以给你一段现成的说明，复制给 Codex 就行。

---

## 四、为回退保留的上一版

每次更新后，Celia 会保留上一个版本。新版本打不开时，会自动退回这一版。

在 **设置 → 关于与更新 → 本机维护 → 为回退保留的上一版** 可以看到保留的是哪个版本、占多大空间。如果当前版本一直用得正常、想腾出空间，可以点「删除」：

- 它会被**移到废纸篓**，清空废纸篓后才会释放空间。
- 删除后，如果当前版本出问题，就不能自动退回那个版本了。
- 正在更新、或者当前版本刚装好还没确认正常时，不能删除，页面会写明原因。

---

## 五、怎么看当前版本

打开 **设置 → 关于与更新**，「应用更新」里的「当前版本」就是。装了小修复时会显示成 0.0.9.1 这样。

---

## 注意事项

- 只从本仓库的 [发布页](https://github.com/Scorpioxyb/celia/releases) 下载 Celia。别人转发的安装包请先按 [校验说明](../VERIFY.md) 核对。
- 卸载：把 Celia 从「应用程序」拖进废纸篓即可。你的数据还在 `~/.celia`，不要的话再自己删。

## 常见问题

**从 0.0.6 更新到 0.0.7 以后，废纸篓里多了一些 Celia 的文件？**
有两类，都可以清空：
- 0.0.6 负责下载和安装这次更新，它会把更新用的临时文件放进废纸篓（可能接近 1 GB）。0.0.7 之后的更新，临时文件会直接删除。
- 以 `Celia-business-skills-` 开头的文件夹，是 Celia 根据你的业务设置自动生成的技能副本。内容仍保存在 Celia 里，新的副本已经生成好了。

**更新会不会把我的客户资料弄丢？**
不会。更新前 Celia 会自动备份，失败会自动恢复。手动替换应用也不会动 `~/.celia` 里的数据。

**更新后需要重新填密钥和邮箱吗？**
不需要。如果你发现需要重填，请把 设置 → 数据 → 数据与备份 页面的提示截图反馈给发布者。
